# Physical measurement inputs

Create one record per measured component/revision. Include:

- CAD object/component ID;
- exact board/part marking and photos/evidence reference;
- date and person measuring;
- instrument and resolution/uncertainty;
- units;
- overall envelope and orientation convention;
- mounting holes and datum definitions;
- connector/component heights and keep-outs;
- acoustic/optical/thermal functional datums where applicable;
- repeated measurements or notes about flexible/compressible parts.

Required next records include the AUX block after trimming, IP2368, actual blower, mic array, speakers/passive radiator, power button and verified drive components.
