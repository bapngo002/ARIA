Được. Với Orange Pi 3B chạy Linux, ta dùng Bluetooth làm **đầu ra loa**, còn microphone của ARIA vẫn dùng USB/I²S riêng.

### Cách đơn giản bằng giao diện

1. Bật loa Bluetooth và đưa vào chế độ ghép đôi.
2. Trên Orange Pi mở **Settings → Bluetooth**.
3. Chọn tên loa → **Pair/Connect**.
4. Mở **Settings → Sound → Output**.
5. Chọn loa Bluetooth và profile **A2DP / High Fidelity Playback**.
6. Mở YouTube để thử âm thanh.

### Nếu không có giao diện Bluetooth

Mở Terminal:

```bash
bluetoothctl
```

Sau đó nhập lần lượt:

```text
power on
agent on
default-agent
scan on
```

Khi thấy địa chỉ loa, ví dụ `AA:BB:CC:DD:EE:FF`:

```text
pair AA:BB:CC:DD:EE:FF
trust AA:BB:CC:DD:EE:FF
connect AA:BB:CC:DD:EE:FF
scan off
quit
```

Đặt loa làm đầu ra mặc định:

```bash
wpctl status
```

Tìm ID của loa Bluetooth trong mục `Sinks`, rồi chạy:

```bash
wpctl set-default ID
```

Ví dụ:

```bash
wpctl set-default 57
```

Thử phát âm thanh:

```bash
speaker-test -c 2 -t wav
```

PipeWire/WirePlumber tự quản lý thiết bị âm thanh Bluetooth thông qua BlueZ; `trust` giúp loa có khả năng tự kết nối lại. [Tài liệu WirePlumber Bluetooth](https://pipewire.pages.freedesktop.org/wireplumber/daemon/configuration/bluetooth.html)

### Nếu loa kết nối nhưng không phát

Kiểm tra:

```bash
systemctl --user status pipewire wireplumber
wpctl status
```

Sau đó khởi động lại âm thanh:

```bash
systemctl --user restart pipewire pipewire-pulse wireplumber
```

Ngắt rồi kết nối lại loa:

```bash
bluetoothctl disconnect AA:BB:CC:DD:EE:FF
bluetoothctl connect AA:BB:CC:DD:EE:FF
```

### Lưu ý cho ARIA

Bluetooth phù hợp để thử nghiệm YouTube và giọng nói, nhưng có ba nhược điểm:

- Có độ trễ khoảng 100–300 ms, làm miệng/mặt robot có thể lệch tiếng.
- Loa có thể không tự kết nối sau khi khởi động.
- Bluetooth và Wi‑Fi 2.4 GHz có thể gây nhiễu lẫn nhau.

Vì vậy, thiết kế ARIA nên hỗ trợ cả hai:

- **Loa Bluetooth:** tiện cho prototype.
- **Loa dây + ampli 3 W:** đầu ra mặc định đáng tin cậy cho bản robot hoàn chỉnh.

Không chọn profile HFP/HSP nếu chỉ phát loa; hãy dùng **A2DP**, vì HFP/HSP có chất lượng âm thanh thấp hơn. PipeWire hỗ trợ các profile Bluetooth và codec A2DP qua BlueZ. [Tài liệu PipeWire](https://pipewire.pages.freedesktop.org/pipewire/)

Bạn đang nói tới **I²S**, không phải I²C. Bluetooth đã kết nối nhưng Orange Pi chưa đổi **đầu ra âm thanh mặc định**, hoặc YouTube vẫn giữ luồng phát trên I²S.

Làm theo thứ tự này:

1. Xem danh sách đầu ra:

```bash
wpctl status
```

Trong phần `Sinks`, bạn sẽ thấy dạng như:

```text
45. Built-in Audio
57. Tên loa Bluetooth
```

2. Đặt loa Bluetooth làm mặc định:

```bash
wpctl set-default 57
wpctl set-volume 57 80%
wpctl set-mute 57 0
```

Thay `57` bằng ID thực tế.

3. Đóng hoàn toàn trình duyệt/YouTube rồi mở lại. Nhiều ứng dụng đang chạy vẫn giữ đầu ra I²S cũ.

4. Thử trực tiếp:

```bash
speaker-test -c 2 -t wav
```

Nếu vẫn phát qua I²S, xem các luồng đang phát:

```bash
wpctl status
```

Trong phần `Streams`, tìm ID của Chromium/YouTube rồi chuyển nó sang loa Bluetooth:

```bash
wpctl move STREAM_ID BLUETOOTH_SINK_ID
```

Ví dụ:

```bash
wpctl move 82 57
```

Nếu loa Bluetooth không xuất hiện trong `Sinks`, chạy:

```bash
pactl list short cards
```

Tìm card có tên `bluez_card...`, rồi chuyển sang A2DP:

```bash
pactl set-card-profile bluez_card.AA_BB_CC_DD_EE_FF a2dp-sink
```

Sau đó:

```bash
systemctl --user restart wireplumber pipewire pipewire-pulse
bluetoothctl connect AA:BB:CC:DD:EE:FF
wpctl status
```

Cách dễ nhất bằng giao diện là mở:

```bash
pavucontrol
```

Rồi:

- **Configuration:** chọn `High Fidelity Playback (A2DP Sink)`.
- **Output Devices:** chọn loa Bluetooth làm fallback/default.
- **Playback:** đổi riêng Chromium/YouTube từ I²S sang loa Bluetooth.

Nếu chưa có `pavucontrol`:

```bash
sudo apt update
sudo apt install pavucontrol
```

Nếu vẫn chưa được, gửi mình nguyên kết quả của hai lệnh sau:

```bash
wpctl status
pactl list short cards
```

Mình sẽ chỉ chính xác ID và lệnh cần dùng cho Pi của bạn.
